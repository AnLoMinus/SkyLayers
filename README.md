## 🧭 תשובה קצרה וברורה

לפי **התורה עצמה** אין מספר מסודר של “מימדים” במובן מודרני. התורה מדברת על **שמים**, **רקיע**, **שמי השמים**, ועל חלוקה בין עליונים לתחתונים. בבראשית נאמר שהרקיע מפריד “בין מים למים”, ובהמשך נקרא הרקיע “שמים”. בספר דברים מופיע הביטוי “השמים ושמי השמים”, כלומר מדרגות/רובדי שמים. ([Sefaria][1])

לפי **חז״ל**, המודל המפורסם הוא: **שבעה רקיעים**. כך אומר ריש לקיש במסכת חגיגה י״ב ע״ב: **וילון, רקיע, שחקים, זבול, מעון, מכון, ערבות**. ([Sefaria][2])

לפי **הקבלה**, משתמשים יותר בשפה של **ארבעה עולמות**: **אצילות, בריאה, יצירה, עשייה**, ובתוכם אינספור מדרגות פרטיות. בתניא מובא שהעולמות בריאה־יצירה־עשייה נובעים מצמצומים כלליים, ואצילות היא מדרגה עליונה יותר. ([Sefaria][3])
